## Findings

### Security

- **Shared scripts can be listed without their link** (3.3). The anon policy
  `scripts."Shared scripts publicly viewable"` is `using (shared = true)`, and
  the signed-in policy has the same arm: anyone with the public API key can
  read every shared script, so the share token protects nothing. Token-gate it
  through a definer `get_shared_script(token)` like the project share link.
  No UI turns `shared` on today, so the exposure is limited to rows shared
  earlier — count them in production (the Supabase connector wasn't
  authorised in this session).
- Portfolio pieces, their media and pitch-board blocks are readable by
  everyone by design (`using true`). A pitch board can carry budget and crew
  blocks — fine because the owner adds them on purpose, but the board should
  say "this is public" (3.3).
- Leaked-password protection is still off (owner, §1).

### Missing for launch

- **No password recovery** (3.4): no "forgot password", no recovery page —
  a forgotten password locks the account.
- **No email delivery** (3.15): notifications are in-app only, and auth
  emails go through Supabase's default sender (low hourly limit). A custom
  SMTP sender is needed before strangers sign up.
- **No staging and no restorable backups** on the free plan (owner
  brainstorm: environments and backups).
- **No moderation** (report / hide / ban) and **no admin screens for the
  catalogues** (crafts, formats, brief questions, channel presets) (3.14).

### Logic and code

- **Half-built script sharing**: `/s/[token]` exists but no control sets
  `scripts.shared` (3.3 — finish it, per "No Mocks").
- **Dead permission model**: `lib/os/permissions.ts` + `access-matrix.ts`
  (global roles; every non-admin is `project_creator`) — `usePermission`,
  `usePageAccess`, `useActionAccess`, `useProjectAccess` have no callers; the UI uses `isOwner` /
  `useCanShape`. `conventions.md` §5 still recommends it (3.10 — removed 2026-10-07).
- **Data access**: 30 files in `app/` and `components/` call
  `supabase.from` directly (110 calls) (3.2).
- `jobs` has two permissive SELECT policies (performance advisor
  `multiple_permissive_policies`) — merge into one (3.9 — merged 2026-10-07; production after the owner applies it).
- `/p` and `/s` render on the client, so a pasted link shows no preview
  (`/shared` does) (3.11 — fixed: `/s` in #141, `/p` 2026-10-07).
- Co-writing is whole-document last-writer-wins with a conflict prompt; a
  CRDT would merge (noted in §4; large, not scheduled).
