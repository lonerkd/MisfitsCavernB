# Session - 2026-11-21: the deep brain, B7(b): the previous draft and places as evidence (BACKLOG 3.21, 3.22)

The honest limit of the reader was "action under a speech in a script with no blank lines reads at F1 about 0.6; it needs the previous draft or a person's correction, not another tuning pass". This is the previous draft, measured, plus the places the project knows. Pure TypeScript, no migration.

**Built**
- **The previous draft as evidence** (`lib/scriptos/previous-draft.ts`, `reading-context.ts`, `decode.ts`, `parser.ts`). A script's latest locked revision (`script_revisions`) is read once with the project's context (cached by text, format and context; a keystroke re-reads only the text being typed), kept to the lines it was read at 90 or more, or that a person settled (a line override finds its line in the earlier text by what it says), and aligned to the later text by a diff (identical lines, then lightly edited ones sharing 70% of their words; a repeated line pairs with its own counterpart). A matched line gets a bounded prior in the decoder (`Params.previousDraft`, 7 cost units). It is never applied to a line the person forced, to a heading (so it cannot move where scenes begin), to a rejected name, to a "cue" that reads as a sentence, or to a label the line's own evidence rules out. A line read as the earlier draft read it is at least 80 sure.
- **The reason is surfaced**: `reasoning` says `Same as in the previous draft (action)` or `The previous draft read this line as X`; the doubtful-reads explanation appends "same as in the previous draft" / "the previous draft read it as X"; the Script tab's *What the reader knows* gains a *The previous draft* section counting lines read the same way and differently.
- **Places** (`project_locations`): a heading in a known place is at least 97 sure ("Known place: X"); a caps `PLACE - TIME` line naming a known place that was read as action is capped at 60 and offered as a scene heading missing INT./EXT. (one tap, *Read as slug*). Places move confidence and the review, never a label, so the editor and the Studio keep agreeing on the scene index.
- **One context, loaded once** (`lib/studio/reading-context.ts`, `loadReadingContext(scriptId)`): the cast, the verdicts, the places, the line overrides and the previous draft under the caller's own access, cached 30 s per script, never a writer's private memory. Unified: a performer's sides (`/call`), the supervisor's lined script, the Cast tab's characters and the Sound page's scene timeline now read as the editor does (they parsed with no context at all); the Studio's scene sync gained the previous draft; the editor builds the same context from its live hooks.

**Audit: what parsed without the shared context, and what is left.** Unified now: sides (`app/(suite)/call/[id]/page.tsx`), lined script (`ScriptSupView`), Cast tab (`useScriptCharacters`), scene timeline (`SceneTimeline`). The editor and the Studio already used one. **Still without it, on purpose:** the public share and review pages (an outsider has no access to project data and must not get it), exports and import (format-less; the element mapping for non-screenplay formats is undecided, 3.22). **Still without it, for later (S each):** the pitch deck's character scan (`PitchDeck`, the project pitch page), the brief (`lib/brief`), Spotify moods and search, the Cavern journey, version diff: each parses once for a summary and writes no scene index.

**Measured** (the ratchet is `lib/scriptos/corpus/previous.test.ts`; 30 seeded scripts per style pasted with no blank lines; the earlier draft is derived by seeded edits: about 10% of speeches and action cut, 8% of lines reworded, new action lines added; the earlier draft's reading is of three kinds). Macro-F1 / action F1, before (no earlier draft) and after:

| Surface | Without | Earlier draft read as it was pasted (engine alone) | Earlier draft kept its blank lines | A person settled every line |
|---|---|---|---|---|
| PLAIN | 0.923 / 0.661 | 0.929 / 0.690 | 0.989 / 0.955 | 0.989 / 0.955 |
| REAL_WORLD | 0.919 / 0.620 | 0.922 / 0.636 | 0.994 / 0.975 | 0.994 / 0.975 |
| INTERNATIONAL | 0.907 / 0.597 | 0.910 / 0.615 | 0.991 / 0.968 | 0.992 / 0.968 |
| Hand-labelled scripts (184 lines) | 0.909 / 0.742 | 0.909 / 0.742 | 0.953 / 0.891 | 0.949 / 0.891 |

Review burden (PLAIN / REAL_WORLD, lines below 75 sure): wrong lines read and not flagged 76 / 89 without, 8 / 7 with an earlier draft kept with its blanks; all wrong lines 124 / 157 to 21 / 14.
Places (30 scripts, every second heading without INT./EXT.: 90 / 120 / 120 headings): offered as a scene heading 0 without, all with, nothing else offered, no label or scene count changed (0 of the 90 seeded scripts read differently with the places known). The ordinary corpus (headings with INT./EXT.) does not move: a heading's confidence was already 100 there, so places only matter for headings written bare.

**What did not work, and what the ratchet caught.** The first weighting (9 cost units, every earlier line carried) gained the same on the pasted-twice case but lost 0.003 macro-F1 on the hand-labelled scripts and invented one cast name (REAL_WORLD, the engine's own wrong guess about a caps action line, confirmed by a neighbouring speech) when the earlier draft was only the engine's reading. Fix: only lines the earlier reading was 90 or more sure of (or a person settled) carry over; then no class of earlier draft reads worse anywhere (the "engine alone" column only gains). Weights 5 to 12 all give the same after-numbers (a plateau; 7 is the smallest that reaches it). Excluding character from the prior was tried and cost INTERNATIONAL 0.006. Carrying the prior also left lines at about 73 sure (just under the doubt line), so the review's precision fell; raising an agreeing line to 80 fixed it.

**Honest limits.** The gain needs a locked revision: a writer who never locks one has no previous draft. The earlier draft read by the engine alone (a pasted script locked as pasted) adds only a little (+0.003 to +0.006), because it carries no information the engine did not have; the big gain is a revision locked while the script still had its blank lines, or one a person corrected. Lines new to the later draft (about a fifth in the corpus) are read as before, so action F1 reaches 0.955 to 0.975, not 1. The previous draft is the latest revision only. The ratchet's earlier drafts are derived from the later one, so they are cleaner than a real rewrite; the hand-labelled set (a rule, not a seed) agrees in direction at half the size of gain.

**Cost** (4,769 lines, about 87 pages): a plain read 117 ms, reading the previous draft 109 ms (once per context change, cached), aligning 30 ms, a read with the prior 145 ms; a test keeps a 100-page script's align under 1.5 s and its read under 2.5x plus 400 ms.
