# Session — 2026-11-07: a narrow desktop window is not a phone

"Continue from your phone / desktop" decided the device by width alone (`max-width: 760px`), so a narrow desktop window (a split screen, a small window, and with `island_v2` the compact dock) was filed as a phone: its places were saved as the phone's and it would be offered the phone's place. `deviceFor(narrow, coarsePointer)` (`lib/pocket/places.ts`) now says a phone is a narrow window **with a touch screen**; `Continue.tsx` uses it for both the saved place and the offer. The floating note itself already clears the compact dock (it sits at 76 px; the dock rests below that). **Verified:** unit tests (`deviceFor`), typecheck, lint, and in a real browser `e2e/mobile.spec.ts` (including Pocket's "continue where the desk left off") and `e2e/island-compact-dock.spec.ts`. No migration.
