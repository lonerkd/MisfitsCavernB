# Session — 2026-11-01: risk tiers for pull requests, and what each worker run costs

Owner asked for a balanced, cost-aware agent system across the Copilot Pro and Claude Pro subscriptions. Facts checked first: Copilot moved to usage-based billing on 2026-06-01 (Pro: about 1,500 credits; the coding agent is billed by tokens, code review by credits plus Actions minutes; completions are free); a Claude subscription token works in Actions and shares one usage limit with chat and interactive sessions. Observed: Copilot reviewed every PR including docs-only ones, so its automatic review spends credits where CI alone is enough.

**A — risk tiers.** `scripts/pr-risk.mjs` (pure `classify`, tested in `lib/agent-risk.test.ts`) puts each PR in low / medium / high from its files; `pr-risk.yml` labels it `risk/*` and keeps one comment. High = database and its tests, the data layer, sign-in, CI and agent workflows, the push script, the agents' rules (`CLAUDE.md`, `AGENTS.md`, `RULES.md`), dependencies, `vercel.json`, legal text. The workflow checks out the base branch, so a PR cannot change its own classifier, and skips fork PRs. Copilot review is requested (once, medium only) only if `PR_RISK_REQUEST_COPILOT=true`; the owner must first turn Copilot's automatic review off, which a workflow cannot do.

**B — run costs.** `scripts/agent-run-stats.mjs` comments each Claude worker run's turns, time, API-price size and refused calls on its issue; `scripts/agent-status.mjs` adds the last 14 days to the status issue (only `github-actions[bot]` comments count).

**Verified:** 50 unit tests for both scripts; mutation checks (dropping the dash escaping, and the worst-file-wins rule, each fail tests); the recorder on a sample log and on a missing one. **Not verified here:** the paginated GitHub calls (this sandbox's proxy blocks GitHub's repo-ID redirects; they run in Actions), the Copilot reviewer request (an assumption about the API; non-fatal if it fails), and the live labels and comment (first proof is this PR).
