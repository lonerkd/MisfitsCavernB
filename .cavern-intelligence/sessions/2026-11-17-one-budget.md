# Session - 2026-11-17: one budget, in Studio › Money (owner: "keep the Studio's budget, remove the other")

**Decision (owner, 2026-11-17):** the suite has one budget screen, Studio › Production › Money. The project page's Budget panel is gone.

**Why more than a deletion:** Studio's Money only *read* the lines ("Set the budget on the project page"); the project page's panel was the only place a line could be made. So the lines' editing moved first: `components/studio/production/BudgetLines.tsx`, shown in Money to a role that runs the budget (`budget.write`): add a line (category and planned amount), delete one (after a confirm), **post a line as an open Jobs listing** (once per line, linked to it), and **Update from the breakdown** (the same breakdown-to-lines sync as before). Every change tells the phase milestones (`announceProgressChange`) and refreshes the table. **Dropped on purpose:** typing an "actual" on a line. Paid already follows the spend (purchase orders and expenses) in the same screen, and two ways to say what was paid disagreed.

**The project page** keeps a small Budget card (the total, how many lines, and a link to Studio › Money; a role with no budget rights still sees the ask). The toolkit's Budget tile, the "Set a budget" milestone and its guide step all open Studio › Money now. `ProductionManager` lost its budget state and handlers (about 150 lines).

**Verified:** unit tests (`BudgetLines.test.tsx`: add, confirm-then-delete, post once; the progress places) and, in a real browser on a built app at 393x852 against the local stack: a line added in Money is in `budget_items` and in the table, "Post as job" made a `jobs` row linked to the line and disabled the button, the project page shows no budget form and links to Money, no page errors. Not clicked through in the browser: delete (covered by the unit test and the confirm path) and "Update from the breakdown" (unchanged code moved). `e2e/project-manager.spec.ts` now asserts the project page carries no budget form instead of adding a line there; not run (it needs the full local stack). **Left (S):** a browser spec for adding and deleting a line in Money.

**The phone audit caught one thing:** the new Budget card's link ("Studio › Money", an inline link) was a sub-44 pt target sideways (it did not show before because the old panel only drew it when the project had lines). It is an "Open the budget" link at 44 pt now. The audit holds against its baseline, and three views got better since the last run, so the baseline was shrunk (`node scripts/mobile-audit.mjs --update`).
