# Session — 2026-10-13: moderation, the first slice (reports)

Before the network opens to strangers there has to be a way to say "this is wrong". Anyone signed in can now **Report** a Lounge message (not their own), a job, or a person's profile — a flag, "What is wrong? One line is enough." One report per person per thing (a repeat is thanked, not duplicated). Admins read the queue at `/admin/reports` (Open / Resolved / Dismissed, who reported, why, a link to the job or profile) and close each one. A report hides nothing by itself.

- **Schema** `20261013010000_reports.sql`: `reports` (RLS on from birth; one SELECT policy — your own or admin's; insert only as yourself and only open; update only by an admin; no delete). Persona test `reports.test.ts` (8) written first and failed before the migration; the full integration suite is green (357). Snapshot and types regenerated. FKs go to `profiles` so the queue can show the reporter.
