# Session — 2026-10-27: link layer, slice C (first slice) — mentions in tasks

**Built:** typing `@` in the hub's "Add a task…" field offers the project's
scenes, characters, places, days, tasks, documents and media; the choice is
stored in the text as `@[Label](entity-id)` and drawn as a chip showing the
entity's *current* name (a rename follows; a deleted target shows struck through).
Saving the task writes `mentions` links from the task to each target
(`syncMentions`: adds new, removes dropped, never itself, a duplicate race is
fine). A chip opens the card: `/studio?project=<id>&card=<entity>` now opens
that card once (flag `entity_cards`).

**Why only tasks first:** a mention is a link between two entities, and only
tasks and documents are entities. A Lounge message is not — making every message
an entity is heavy on a hot table, so mentions in the Lounge need a decision
(BACKLOG 3.18 c). Tasks have no text editing yet, so mentions are set when the
task is created.

**Tests:** `lib/film/mentions.test.ts` (15: parsing, rendering with current
labels, brackets in a label, the `@query` at the caret, inserting, diffing,
tokenising picked labels), `lib/film/sync-mentions.test.ts` (4). RLS is the
slice-A policy (anyone on the project links; creator or shaper removes), already
persona-tested. **Verified:** typecheck, lint, 1702 unit tests, build (known
intermittent `SecurityFatalError` passed on rerun), page-size budget. The picker
was not clicked through in a browser.

**After Copilot's review (six findings, all real):** the picker's roles moved to
the button with `aria-activedescendant`; the trailing space after a pick closes
the list so Enter submits; `tokenize` skips a label that continues into a longer
word (`@Rooftop`); `syncMentions` upserts with duplicates ignored so one existing
link no longer drops the others; the Studio deep link now opens the card on
in-app navigation (lazy initial state + change); and the raw `@[Label](id)`
markup no longer leaks: `20261031000500_entity_label_plain_mentions.sql` labels a
task by its plain text, and Today and the assignment notification read it with
`plain()` (integration test added).
