# Session — 2026-11-07: the phone experience, slice 4 — tools around the keyboard

The owner: the keyboard takes half the screen; the rest has to stay usable, with the tools. A phone keyboard has no Tab, no Ctrl-Z, no Ctrl-F, so the old six-button element strip was not enough. `PhoneToolStrip` (replaces `PhoneElementBar`) sits on the keyboard: put the keyboard away, undo, redo, change the line's element type (Tab's cycle, extracted from the key handler as `cycleElement`), previous/next scene, Scene/Action/Character/Dialogue/Transition, find, notes, tools sheet, menu sheet. It scrolls sideways (a row of tools is the one right place for that) and cancels `pointerdown` so the keyboard and caret stay. The editor reserves room for it (the container pads its bottom) and hides the status line while typing, so nothing writes under it; in landscape, where the top bar is gone, Tools and More on the strip are the way to every sheet. Tests: 5 unit (every tool calls its action, pointerdown cancelled, compact buttons ≥ 40 pt) and `e2e/phone-editor.spec.ts` presses undo, redo, change type and put-away on the faked keyboard in both orientations. **Left:** the same strip idea for the Lounge composer, Studio forms and On set; **not verified** on a real iPhone.
