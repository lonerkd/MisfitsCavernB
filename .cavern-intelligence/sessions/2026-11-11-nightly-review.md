# Session - 2026-11-11: the nightly review, and rule 6 reworded

**Why:** Copilot's automatic code review used 1,499 of the month's credits (nearly all of it; all on this repository) because it reviews every push to a PR. The owner asked for the review to be part of the nightly run, to cover everything that changed in the repository and in production, and to leave fixing its comments as the first task of the next day, with no Copilot credits. The owner also asked for the Git rule to say what it means.

**Built:** `.github/workflows/nightly-review.yml` (07:37 UTC and by hand; dormant until `CLAUDE_CODE_OAUTH_TOKEN` is set), `scripts/nightly-review-input.mjs` (reads merged PRs, commits, unmerged branches, production deployments, failed runs, the diff on `main` and the previous review; writes `nightly-input.md`; says whether the day was quiet), `scripts/nightly-review-prompt.md` (the rubric: P0 to P3, the output shape), `scripts/nightly-review-post.mjs` (refuses a review without its sections, posts one issue labelled `nightly-review`, closes the earlier open one with a pointer), `scripts/nightly-review-lib.mjs` (the window, the input, the validation: 14 tests in `lib/ci/nightly-review.test.ts`). The SessionStart hook prints the open review's unchecked findings ("START HERE"), and `RULES.md` makes them the first task of the day. The medium risk tier no longer promises a per-PR AI review. Design and decisions: `plans/2026-11-11-nightly-review.md`.
**Also:** `RULES.md` rule 6 now reads "preview first, then main": the point is that a change is tried on a branch and its preview, never on `main`; an agent may merge its own green PR; checks are never bypassed (`main-2` has no bypass, so it is enforced as well as asked). The SessionStart hook took minutes on Windows (two git calls per session note); it now makes two git calls in all (3 s).
**Verified:** the unit tests for the review's parts; syntax of the scripts; the hook against the real repository. **Not verified:** a real run (it needs the secret and GitHub's API); the prompt's output on real data; the claim that it costs one ten-minute run a night.
**Owner, once:** turn Copilot's automatic review off, then run the workflow by hand once and read the first review (see the plan).
**Left (BACKLOG 3.34):** run `checks` when a PR is ready for review, not on every push (the larger Actions-minutes saving); tune the rubric after a week of real reviews.
