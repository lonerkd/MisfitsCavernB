# Session — 2026-11-07: the phone pill follows the same keyboard as everything else (phone shell, first piece)

The tab-bar pill hid itself with its own guess (a focus listener: any text field focused meant "keyboard up"). Everything else on the phone (the island, floating tools, the scroll area's padding, the editor's strip) already reads `usePhoneLayout().typing`, which measures the real keyboard through `visualViewport`. The pill now reads that too and its own listener is gone, so one definition of "typing" drives the whole shell: a touch phone with its keyboard up hides the pill; a hardware keyboard (no on-screen keyboard) no longer hides it. Behaviour is otherwise unchanged. Existing mobile specs still cover the pill; a spec for the pill under a faked keyboard is left. **Left in the shell (BACKLOG 3.41):** a tab bar that rides the keyboard instead of leaving, every page's content clear of it, a browser spec per surface in both orientations, and the CI audit.
