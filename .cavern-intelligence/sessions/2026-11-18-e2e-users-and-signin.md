# Session - 2026-11-18: users and sign-in through the helper (BACKLOG 3.37, tier 2)

The owner asked for the rest of 3.37. After tier 1 (the backend), about 100 specs still made their own users with `admin.auth.admin.createUser`, signed in by a five-line block and deleted the user in `afterAll`. Counting the shapes showed they were nearly identical, so a codemod (kept out of the repo) did it: **105 sign-in blocks** became `signInAs(page, { email, password })` (a plain function exported from `e2e/support/stack.ts`, so a describe-level helper can call it without a `Stack`), **107 `createUser` calls** became `stack.createUser({ email, password, username })` (the helper now takes those three options, so a spec's own constants carry over), and **71 `deleteUser` lines** went (the helper deletes users at teardown, after the spec's own `afterAll` has removed their rows). About 500 net lines left the specs. TypeScript was the safety net (`npm run typecheck` covers `e2e/` since tier 1): it flagged 3 spots, all helper functions with no `stack` in scope, done by hand (`onboarding`, `studio-journey`; a stray scope edit in an unrelated `page.evaluate` fixed), and lint found 8 `admin` variables that had become unused.

**Verified, against a production build and the local stack.** All specs, three workers: 204 passed, 8 failed, 6 skipped, 4 did not run (they follow serial failures), while the pre-push hook was also running the unit tests (which then failed too, from the same load: alone they pass, 3,145). The 8 failed files were re-run alone, one worker: 16 of 17 tests passed (including `change-impact`, so the note in tier 1 that it fails on `main` was wrong: it is load-sensitive, as is the rest); `script-supervisor` failed once more, then passed twice alone, both the `main` version and this branch's. So nothing in this change fails by itself. **The flakes are real and left (a sweep):** `script-supervisor` (scene picker: "Unlink scene 1" not there within 10 s), `editor-cowriting` and `editor-offline-merge` (Yjs sync waits), `accessibility` (an axe contrast reading mid-animation), `admin-support-analytics` (a database read right after the save), `mobile`, `phases`.
