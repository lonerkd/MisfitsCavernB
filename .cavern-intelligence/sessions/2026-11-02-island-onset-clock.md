# Session — 2026-11-02: the island says where the shoot day is

On a shoot day the island's rest pill said only "On set · Day 1". It now also says where the day is: **"On set · Day 1 · Rolling · 3h 01m on set · 59m to wrap"** (the phone pill is shorter: "Rolling · 3h 01m on set"). The phase (crew called, rolling, lunch, wrapped), the time on set with lunch taken out, and the time to the call sheet's planned wrap, or "25m over" once it passes. Nothing is said before the crew call is stamped.

**How:** the pure `onSetLine(status)` (and `duration`) in `lib/island/onset.ts` word the existing `dayStatus` from the On set view (`lib/studio/onset.ts`), so the island and the On set screen cannot disagree. `useOnSet` reads the day with one narrow call (`studio.getDayClock`: the day's call sheet and its five clock-stamp kinds, not the project's notes and continuity) every 30 seconds, only while today is a shoot day and the person has not stepped out; no realtime subscription (the island is on every page and the phone's pill asks too), so a change shows within 30 seconds. Nothing is said without a crew-call stamp, and the phone pill ellipsizes within 58vw.
