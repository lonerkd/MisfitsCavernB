# Session — 2026-11-08: the scene's entity card shows its records

The last piece of the plan that linked the role tools to scenes and characters. A scene's **entity card** (behind `entity_cards`) now has a **Records** fact, the same count the scene passport shows ("2 camera reports, 1 makeup"). `cardOf` takes an optional `recordsByScene` (the map `StudioContext` already builds from one live query for the project) and adds the fact only for a scene with linked records; for any other scene, and when no map is given, nothing changes. A scene's entity id is its scene id, so no mapping was needed. **Tests:** two in `lib/film/card.test.ts` (the fact lists the records by tool; nothing when none is linked, when the map is empty or absent, or when the records belong to another scene). The film and card suites pass. No database change. Nothing is left from [the plan](../plans/2026-11-08-records-linked-to-the-graph.md).
