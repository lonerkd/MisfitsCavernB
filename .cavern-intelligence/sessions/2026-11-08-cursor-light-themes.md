# Session — 2026-11-08: the custom cursor on the light themes

Owner: cursor display issues on the light themes. **Cause:** the cursor's dot and ring both used `mix-blend-mode: difference`, which inverts against whatever is under it. On a dark page the light dot read; on a light page a dark dot (`--fg`) minus a light page came out light-on-light, and the accent ring turned its complementary colour (orange to blue). **Fix:** no blend mode; the dot keeps the theme token (`--fg`, the accent for actions) with a 1.5 px halo in the page's own colour (`--bg`), which keeps it readable over any surface (an image, a dark card on a light page); the ring keeps its theme-token borders. **Tests:** `CustomCursor.test.tsx` (neither part blends with `difference`, the dot has the halo and the token; nothing is drawn without a fine pointer). **Not verified by eye on each light theme** (Paper, Editorial, Slate, Lagoon…): run `npm run dev`, switch the theme in Settings and move the pointer over text, a button and an image.
