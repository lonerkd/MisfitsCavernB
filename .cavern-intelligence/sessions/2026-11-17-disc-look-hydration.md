**Hydration error #418 on the editor, found and fixed.** Reproduced against `next dev` (the production build only says "#418"): the status bar's `SyncStatusChip` drew an "Offline" chip on the server and nothing in the browser. Cause: Node 21+ defines a global `navigator` with no `onLine`, so `typeof navigator === 'undefined' ? true : navigator.onLine` read as offline on the server. `readOnline()` in `lib/scriptos/storage.ts` treats "no answer" as online (unit-tested); `useOnSetSync` had the same line. A rebuilt app logs no hydration error on the editor at 393x852 or 852x393.
