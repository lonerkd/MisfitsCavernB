# Session — 2026-10-12: View as (owner preview)

The owner asked how to switch and emulate views as roles. There was no way to; now the project's real owner has **View as: Me · Crew · Outsider** in the project hub's header.

- **Crew:** owner-only controls go (logline editing, the phase mover, the production manager's deletes, Studio's owner actions); a banner says what this is, with **Back to me**.
- **Outsider:** the hub and the Studio render what an outsider gets from the database — the same as a project that does not exist (no title, no crew, no files).
- **Honest by design:** it is a preview of the *interface*, never of access. RLS is untouched and nothing is written (the e2e checks the row afterwards). Per project, for the tab's session (`sessionStorage`), only offered to the real owner.
- Built on one small store (`lib/os/viewAs.ts`) read where `isOwner` is decided: the hub page and `StudioContext`. Other surfaces that compute ownership on their own (Lounge `ownsActive`, the call-sheet page) do not follow the preview yet — BACKLOG 3.23.
