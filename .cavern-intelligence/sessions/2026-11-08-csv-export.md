# Session — 2026-11-08: a spreadsheet file from every printed tool

Rather than a separate Export menu per tab, the print kit's tables are already the data, so `lib/print/csv.ts` turns any `PrintDoc` into CSV (each table's header, rows and totals; CRLF; tables apart by a blank line) and `lib/print/download.ts` saves it (a byte-order mark first, so Excel reads accents and non-Latin text). `PrintButton` and the record tools' button now carry **Print / PDF** and **CSV** side by side, so every tool that prints (the budget, schedule, crew, locations, shot list, cast, day out of days, revisions, all 21 record tools) gives a spreadsheet with no per-tool work; a page with no table says so instead of saving an empty file. **Safety:** a typed value that starts with `=`, `+`, `-` (when not a plain number) or `@` gets a leading apostrophe, so opening the file in a spreadsheet can never run it as a formula (a known way to attack whoever opens an export). **Tests:** `csv.test.ts` (quoting, formula neutralising, totals, blank line between tables, file naming), `PrintButton.test.tsx`.
