# Building a project should feel like play, and the suite should work for more than film (BACKLOG 3.54)

Owner, 2026-11-22. Said in their own words: tools like FilmUsage and StudioBinder already cover the scheduling-and-paperwork side; "we just need to get to a point where building a project in the cavern feels interesting and like a video game, not just like a bunch of lists and stuff to fill out. It should feel like Lego and painting and dragging stuff around, and tangents into different ideas and concepts, exploring references, and search that is deep linked into the project, to project-contextualize results that inspire and juice creativity. While providing industry-leading (but at minimum competing) tools for all roles, but also we need to make it not so film-centric, so it works as a notes app if you wanted it to just store stuff and connect your Spotify and use the lounge to chill with your guys."

This is a **direction**, not a task. It sets how the next product slices are judged; it is not built yet, and the slices below are proposals for the owner to pick from.

## The honest read

- **Parity is a floor, not the pitch.** For the role tools (schedule, call sheets, breakdown, budget, sides), the bar is "at minimum competing" with FilmUsage, StudioBinder and the rest. The 2026-11-15 role-suites audit says every craft has a working suite; nobody has yet run the practitioner protocol against a competitor, so "competing" is unproven.
- **The edge is the connected graph plus a creative surface.** Competitors are lists and forms. The Cavern already links scenes, characters, locations, shoot days, people and references as real rows with a universal links layer. What it lacks is a surface where that graph can be *played with*.
- **Part of "not film-centric" already exists.** Formats include Podcast, Blog / Newsletter, Video Game, Copywriting, Advertising, Music Video; Spotify, the Lounge and the portfolio are not film-specific. What is missing is a project that is *only* notes, storage and people, with no phases and no production vocabulary.

## What the suite already has that this builds on

Mood boards (free positions, z-order, library cards and note cards, share links, search, slideshow), the look-board per character, the Library (uploads, links, Openverse and Pinterest search with credit), the beat board, the links layer (`links`, `entities`), the Cavern experience, the film graph, formats with their own phases, Spotify, the Lounge, the portfolio.

## Principles (match the notification principles, `2026-11-22-notification-system.md`)

1. **Manipulate things, not forms.** Drag, place, link, branch. A list of fields is the fallback, not the front door.
2. **Context everywhere.** Search, suggestions and "what next" are shaped by the project (its brief, format, mood, what is on its boards), never generic.
3. **Tangents are first-class.** Any item can spawn a side exploration (a board, a note thread, a reference hunt) that stays linked to where it came from and can be folded back in.
4. **Progress is play, not guilt.** Showing where a project stands as a map, with tools as pieces; no streak pressure, no dark patterns.
5. **The suite shrinks to the person.** A plain notes-and-storage project must be a first-class way to use it.

## Proposed slices (the owner picks the order)

1. **A free project** (S/M): a project type with no phases, no production tools forced, just notes, files, boards, links, Spotify and its channel. Makes "works as a notes app" true and tests how little the suite needs.
2. **The canvas** (L): one free surface per project where any item (scene, character, location, reference, track, note, person) can be placed, linked and grouped; the mood board generalised, not a second tool.
3. **Tangents** (M): "branch from here" on any item: opens a canvas pre-seeded with that item and its links, with a way back; the branch can be merged into the parent canvas.
4. **Contextual search** (M/L): one search that takes the project's context (brief, format, the item you are on) and returns references, people, jobs and your own notes together; results can be dropped onto the canvas.
5. **The map** (M): the phases and milestones drawn as a map you move through, with tools as things you pick up, replacing the checklist feel (builds on 3.52).
6. **Competitor parity pass** (M): run the practitioner protocol for the main roles against FilmUsage and StudioBinder, list what each does that we do not, and rank.

## Not doing

Turning every list into a game; points, badges or streaks; a second tool beside the mood board that does the same thing; a rewrite of the production tools.

## Open (owner)

Which slice first; whether the free project replaces or sits beside the formats; whether the canvas replaces mood boards or generalises them (the plan above says generalise); whether tangents should be able to cross projects.
